# Parsing_retail

## Zolla

Требуется Python 3.10 или новее.

```powershell
python -m pip install lxml
python zolla_parser.py --limit 20 --output zolla_test.csv
python zolla_parser.py --output zolla.csv
```

Без `--limit` скрипт обходит все уникальные ссылки на карточки из карты сайта Zolla.
Можно передать одну или несколько ссылок через повторяемый параметр `--url`.
По умолчанию работает один поток с паузой 0,5 секунды перед каждым запросом.
Пауза настраивается через `--delay`, число одновременных загрузок — через `--workers` (от 1 до 8).
Начните с 4 потоков. Если сайт возвращает HTTP 429, увеличьте паузу или уменьшите число потоков.

Для замера на одинаковой выборке выполните команды по очереди:

```powershell
python zolla_parser.py --limit 100 --delay 0.2 --workers 1 --output zolla_speed_1.csv
python zolla_parser.py --limit 100 --delay 0.2 --workers 4 --output zolla_speed_4.csv
```

В конце каждого запуска скрипт выводит время в секундах (включая загрузку карты сайта),
число сохранённых карточек, ошибки и среднюю скорость.
Если на Windows для HTTPS требуется `truststore`, замените `python zolla_parser.py` в командах на
`python -c "import truststore; truststore.inject_into_ssl(); import zolla_parser; raise SystemExit(zolla_parser.main())"`.
Полный обход может занять несколько часов. Покрытие зависит от того, какие карточки Zolla включила в карту сайта.

CSV в UTF-8 с BOM, разделитель `;`. Одна строка на карточку товара в конкретном цвете.

| Колонка | Содержимое |
| --- | --- |
| `hierarchy` | Разделы из навигационной цепочки карточки через ` > `. Пусто, если цепочки нет. |
| `name` | Название товара |
| `article` | Артикул Zolla. В Excel при импорте задайте тип «Текст», чтобы сохранить начальные нули. |
| `current_price` | Текущая цена в рублях |
| `old_price` | Перечёркнутая цена в рублях, если она выше текущей |
| `out_of_stock` | `1` — по данным карточки ни один размер не доступен, `0` — доступен хотя бы один размер, пусто — статус неизвестен |
| `product_url` | Ссылка на карточку |

Цены и наличие берутся из карточки для региона и магазина, которые сайт возвращает без ручного выбора. Остатки по всем магазинам отдельно не проверяются.
При ошибках скрипт пишет адреса проблемных карточек в консоль, сохраняет собранные строки в файл с суффиксом `.partial` и завершает работу с кодом 1. При успешном запуске файл получает имя, заданное в `--output`.
